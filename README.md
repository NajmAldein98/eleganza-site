# موقع إليغانزا للخياطة

الموقع الرسمي لمحل Eleganza للخياطة الرجالية في جدة.

- `index.html` — الصفحة كاملة (التصميم والنصوص والبرمجة)
- `img/` — الشعار والصور
- `netlify.toml` — إعداد النشر على Netlify (موقع ثابت بدون بناء)

أي تغيير يُرفع إلى الفرع `main` ينشره Netlify تلقائيًا.

## الإضافات (نوفمبر ٢٠٢٦)
- `extras.js` و `extras.css` — أقسام: مقاعد الموسم، قصص إليغانزا، مستشار القماش، تتبّع ثوبك، ثوب هدية، علّمنا وش تحب
- `thobe/` — شهادة ميلاد الثوب (رمز QR داخل الياقة)
- `gift/` — بطاقة هدية الثوب
- `staff/` — صفحة الفريق: الطلبات ومراحلها، أذواق العملاء، مقاعد الموسم، الهدايا (تدخلها برمز المالك)
- `netlify/functions/extras.mts` — الخادم (`/api/elg/...`) على Netlify بنفس رمز المالك
